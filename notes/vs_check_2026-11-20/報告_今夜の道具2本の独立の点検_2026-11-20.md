## 4. decoy の雑音なしの dry を種を変えて20回（`seeds20.py` → `seeds20.txt`、`decoy_dry_none_20seeds_scores.txt`）

- **走らせ方**：`--dry-clifford-sentinel` で1回組み、その写しで dry を20回。
  - 種は 10⁸ × i + 7（i = 1〜20）。道具の刻み（回路ごとに 10⁶、部分ごとに 10⁴）と重ならない。
- **結果**：条件つきの部分 6 × 20 = 120 個の言葉は、**すべて SAME WITHIN ERROR**（LESS も MORE も 0）。

| 数 | 結果 |
|---|---|
| d/SE | 平均 +0.03、**SD 0.61** |
| (p − s)/SE（折り返さない差） | 平均 −0.03、SD 0.98。2 SE を越えたのは 3 |
| 見込み：d が正規分布なら | 2 SE を越えるのは 4.6 %、120 個で 5.5 個 |
| 見込み：雑音なしの d = \|s − v\| − \|p − v\| | SD/SE = √(1 − 2/π) = **0.603**。2 SE を越えるのは **0.21 %**、120 個で 0.25 個（モンテカルロ、2×10⁶） |

- **なぜ 4.6 % にならないか**：雑音なしでは、s と p がどちらも v のまわりに散らばる。そのため d は「半正規分布の差」になり、散らばりが SE の式（√(SE_s² + SE_p²)）の 0.60 倍しかない。0個は、この見込みと合う。
- **装置の夜には効かない**：s と p が v から離れていれば、d ≈ p − s になり、2 SE の閾値は 4.6 % に戻る。

| s と p が v からどれだけ下か | 2 SE を越える割合 |
|---|---|
| 0 | 0.21 % |
| 0.005 | 0.86 % |
| 0.01 | 2.6 % |
| 0.02 | 4.5 % |
| 0.06 | 4.5 % |

- 11-18・11-19 の夜は、s が v より 0.06 下だった（0.734 対 0.793）。今夜の判定の閾値は、宣言どおりに働く。
- 「雑音なしで LESS / MORE が約 4.6 % 出る」で dry の健全さを見ることはできない。見るなら、(p − s)/SE の散らばり（ここでは SD 0.98）か、例示の雑音つきの dry で数える。
- 職場クロードの README にある「雑音つきで D0 の B が −0.026 で LESS（撃ちの揺れ）」は、s が v から離れた場合なので、4.6 % の見込みどおりの出方。

**2 の理由**
- オーナーの言葉は、もとの表で行 2 と行 3 が重なる場合（D1 で A と B が失い、D2 の A も失う）を決めたものと読める。もとの行 3 は D2 を「-」としていたので、重なりはこの場合に限られた。
- D1 で A と B が失い、D2 の A が失わない場合は、もとの表では行 3 だけに当たっていた。もとの行 2 は D2 の A が失うことを求めていたので、行 2 には当たらない。
- 新しい表では、行 3 を「D1 の A が失わず、B が失う」と狭めた。そのため、この場合は「D1 の A が失い、D2 の A が失わない」行 6 に移る。
- 行 6 の読み（Z が先頭なら A が失い、Z が最後なら A が失わない：並びの読みと逆で、読めない）は、D1 の B も失っていても変わらない。行 6 でよい。
- ただし、オーナーの言葉を「D1 で両方が失えば、D2 によらず行 2」と読む余地も残る。家に確かめる、という職場の書き方のままでよい。
