## 問いへの答え

1. **twirl なしの (de) は、t = 3 で正の側に残るか**：残らない。この模型では負の側に出た。coh0.05 で −0.008、coh0.10 で −0.034。
   - (d) も同じ向き（−0.009、−0.038）。
   - (e) は正の側（+0.011、+0.041）。
2. **鏡だけ twirl すると、0 に寄るか**：寄らない。
   - (de) の d：coh0.05 で −0.009、coh0.10 で −0.039。twirl なしとほとんど同じか、わずかに外側。
   - (d) の AGREES は、むしろ下がった（coh0.10 で 33 → 20%）。
   - 鏡だけ twirl すると、鏡のずれは確率的な雑音に変わる。けれども、前へ進む回路のずれは決まった向きのまま残る。そのため、2 つの差が埋まらないと読める。
3. **全部 twirl すると**：
   - (d) と (de) の d は、ほぼ 0 になった（+0.001〜+0.006）。AGREES も 87〜97% に戻った。
   - 代わりに、(e) の d が大きくなった（+0.022、+0.083）。(e) の AGREES は 17%、0% に下がり、(a) も coh0.10 で 30% に下がった。
   - 読み出しの回路は twirl していないので、(e) はほかの回路とそろわなくなる。全部 twirl するなら、読み出しの回路のそろえ方を別に決める必要がある。
4. **雑音なしで全部 AGREES になるか**：ならない。
   - t = 1 と 3 の 60 セルのうち、7 セルが DIFFERS（t = 1 で 6、t = 3 で 1。none と mirror は同じ）。
   - どれも |d| がおよそ 0.009 で、t·SE（およそ 0.008〜0.009）をわずかに超えたショット雑音ぶんの差。(b)(c)(d) は雑音なしでは同じ量を見ているので、3 つそろって DIFFERS になる。
   - 5% なら 60 セルで 3 つほどのはずなので、7 は多め。雑音なしでの SE の幅を、家で見てほしい。
   - 鏡は、雑音がないと答えが 1 つに決まる。そのため、none と mirror は同じ数になる。
