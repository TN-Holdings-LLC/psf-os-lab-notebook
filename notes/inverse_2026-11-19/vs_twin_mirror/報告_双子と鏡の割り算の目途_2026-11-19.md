# 双子と鏡の割り算：食い違いは位相のずれの目印になるか（職場の VS、2026-11-19 その6、軽い目途）

作成：職場の VS（2026-11-19 08:10 CET ごろ）。宣言ではありません。机の上だけで、IBM・GitHub には触れていません。

**雑音はすべて例示です**（手で書いた値。装置に合わせていません。校正の数字は読んでいません）。

- 環境：Windows、Python 3.11、qiskit 2.5.2、qiskit-aer 0.18.0。
- 双子：psf-os 5e4a936 の `psf_os/twin.py`（`twin`、`check_same_schedule`、`z_exact`、`kept_share`）を、変えずに使った。
- 計算はすべて手元の CPU で、約12分。n = 12 の点も含めて Pod は要らなかったので、立てていない。

## 一言

**仮説のままの形では「なさそう」。** 「偶然の誤りだけなら、双子と鏡の残った割合はおおむね一致する（g ≈ 0）」が成り立たないため。

- 偶然の誤りだけ（A）でも、g は深さとともに 0 から離れる：
  - L = 2 で +0.015、L = 8 で −0.020、L = 20 で −0.100。
  - 40 000 撃ちでは、どれも 2 SE の 3〜21 倍ある。
- そのため、「g が 0 から離れたら位相のずれ」とは読めない。

一方で、位相のずれは g を大きく動かす：
- L ≥ 8 では、C（0.05 rad）の g − g_A は、D の g − g_A の 6〜8 倍余り。
- 撃ち数は足りる。40 000 撃ちで、2 SE の 25〜60 倍。

ただし、それを読むには「偶然の誤りだけなら g はいくつか」という基準が要る。基準は雑音の模型から出すことになり、「模型を使わない」という前提が崩れる。

## 回路と作り方

- 回路：`inverse_desk.py` の蹴り鎖。角度と seed は同じ。
  - n = 8、L = 2, 4, 8, 12, 20。|0…0⟩ から、すべての量子ビットを測る。
  - n = 12 は L = 8 の1点だけ。
- sx / rz / cz の基底に組み直した：
  - rx(θ) = rz(π/2)·sx·rz(θ+π)·sx·rz(π/2)。大域位相のほかは、元と同じユニタリーであることを確かめた。
  - 同じ量子ビットで続く rz はまとめた。ほかのゲートはまたいでいない。
  - 1つの rx に sx が2つ要る（rz・sx・rz の1つの sx では、一般の θ は作れない）。
- 双子：`twin(U)`。どの点でも `check_same_schedule` を通った。
- 鏡：U のあとに U⁻¹。sxdg は rz(π)·sx·rz(π) にした。
- 割合の出し方：
  - k_twin = kept_share(z_twin, z_exact(双子))。どちらも 8 個（または 12 個）の ⟨Z⟩ を使う。
  - k_mirror = √kept_share(z_mirror, 1…1)。鏡の正確な値はすべて +1。
  - 推定 = 生の中央の ⟨Z⟩ ÷ k。k_true = 生 ÷ 正確な値（中央）。g = k_mirror − k_twin。
- 雑音：
  - A：cz の後に 2 量子ビットの脱分極 0.01、読み出しの反転 0.02。
  - C：A に、cz の後の ZZ(0.05) を足す。
  - D：A に、sx の後の 1 量子ビットの脱分極 0.002 を足す（sx は rx 1つに2つなので、元の desk の rx に掛けたものの約2倍効く）。
  - C'：A に ZZ(ε) を足し、ε = 0.02、0.05、0.1 と振る。
- 撃ちあり：
  - 1点ごとに、利用者の回路・双子・鏡を各 40 000 撃ち。
  - n = 8 は5回、n = 12 は3回くり返した。
  - 2 SE は1撃ちの統計量から出した（量子ビットどうしの相関も含む）。k_mirror には √ のデルタ法を使った。
  - くり返しの SD は SE とほぼ同じで、2 SE は過大でも過小でもない。

**大事な前提：この回路では、双子は「X の蹴りのない鎖」になる。**
- θ ∈ [0.2, 0.6] なので、rz(θ+π) は必ず rz(π) に丸まる。双子の rx は恒等になる。
- そのため双子の状態は、ずっと |0…0⟩ のまま（`z_exact` はどの点でもすべて +1）。
- その結果、双子は ZZ の位相のずれを**まったく見ない**。cz の後の Z 型の誤りも見ない。
  - 無限撃ちでは、C の k_twin は A と同じ値になった。
- これは目印の仮説には都合がよい（双子は位相のずれで動かない）。一方で、偶然の誤りのうち双子に見える割合が利用者の回路と違うので、A でも g ≠ 0 になる理由の一つになっている。
- 蹴りの大きい回路（θ が π/4 を越える）なら、双子は別の形になる。今回は見ていない。

## 目途の問い（指示の4）への数

1. **無限撃ちで、A・D と C の g ははっきり分かれるか。**
   - g そのものの大きさで比べる（基準なし）：
     - L = 8 では \|g_C\| / \|g_A\| = 5.7、\|g_C\| / \|g_D\| = 3.5。
     - L = 20 では 3.3 と 2.6。
     - L = 2〜4 では分かれない（L = 2 で 0.6、L = 4 で 1.4）。
   - A を基準にした差で比べる（表2）：
     - L ≥ 8 では、C の動きは D の 6〜8 倍余り（6.0〜8.4）。
     - ε = 0.02 では、D とほぼ同じ大きさで、分かれない。
   - 向きは仮説と逆だった：
     - 位相のずれがあると、鏡の k は**下がる**（L = 8 で 0.815 → 0.724）。
     - ZZ(+ε) は、U の cz の後にも U⁻¹ の cz の後にも同じ符号で入るので、往復で打ち消さずに重なる。
     - そのため g は負の向きに動く。
2. **40 000 撃ちで、その差は 2 SE より大きいか。**
   - ε = 0.05 では、どの L でも大きい（L = 2 でも 2 SE_diff の約2.3倍）。
   - ε = 0.02 は、L = 2〜4 では 33 000〜64 000 撃ちで 2 SE、L ≥ 8 では約 3 100 撃ち以下。
   - **撃ち数は詰まりどころではない。** 詰まるのは、A の基準 g_A が 0 でないこと（A だけで 2 SE の 3〜21 倍）。
3. **C で、双子の割り算は鏡の割り算より正確な値に近いか。**
   - L = 2、8、12、20 と n = 12 では近い：
     - L = 8：+0.033 と +0.148。
     - L = 12：+0.199 と +0.313。
     - L = 20：+0.020 と −0.128。
     - n = 12：+0.059 と +0.084。
   - L = 4 だけは逆（−0.006 と +0.002。どちらも小さい）。
   - ただし L = 12 では、双子の誤差も +0.20 ある。位相のずれは信号を縮めるだけでなく、形を変えるため（k_true = 1.60）。どの割り算でも直らない。

## 所感（深追いしていない）

- 仮説のままの形（模型なしで、g ≈ 0 からのずれを読む）は、この回路と雑音では成り立たない。理由は2つ：
  - 双子と鏡では、偶然の誤りの見え方が違う：
    - 双子は |0…0⟩ のままなので、Z 型の誤りを見ない。
    - 鏡は cz が2倍で、平方根をとる。
  - そのため、A でも g が 0 からずれる。
- 残るのは弱い形で、「同じ回路を深さを変えて並べ、g の傾きが A と D の幅を越えて急に動くか」を見ること。ただしその幅を言うには、雑音の模型が要る。
- 続けるなら、前に考えることは2つ：
  - 蹴りの大きい回路では、双子が |0…0⟩ に留まらない。そこで g_A が 0 に近づくかを見る。
  - 偶然の誤りのうち、双子と鏡の両方に同じだけ見える部分（例：読み出し）を先に除いてから比べる。
- 今日はここで止めた。
